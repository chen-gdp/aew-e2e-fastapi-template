# Repository instructions

- Keep product code under `src/task_api/` and tests under `tests/`.
- Run `pytest` before delivery.
- Preserve consumer-owned content under `docs/` and `specs/` when installing or
  updating AEW.
- Use `/gl-goal` for AEW workflows; coding-agent `/goal` commands are separate.
- Do not commit `.agents/local/`, linked worktrees, generated reviews, or fix
  plans.
